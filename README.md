## 📖 Overview

Welcome to the **Smart Home Packet Tracer Project**! This repository features a comprehensive Cisco Packet Tracer simulation demonstrating a modern Smart Home network. It illustrates the seamless integration, connectivity, and management of various Internet of Things (IoT) devices within a typical home network architecture.

This project serves as a practical example of how computer networks function in a smart environment, covering wireless configurations, IP addressing, and centralized IoT control.

---

## 📂 Repository Contents

*   **`Smart_Home.pkt`** 🖥️: The core Cisco Packet Tracer project file containing the full network topology, device configurations, and IoT logic.
*   **`CN report.docx`** 📄: A detailed Computer Networks project report providing an in-depth analysis of the network design, implementation phases, and theoretical concepts applied.

---

## ✨ Key Features & Capabilities

*   **Extensive IoT Integration**: Simulates a wide array of smart devices including:
    *   🚪 Smart Doors & Windows
    *   💡 Smart Lighting systems
    *   🌡️ Smart Thermostats & HVAC controls
    *   🌀 Smart Fans and Appliances
*   **Realistic Network Architecture**: Built around a Home Gateway/Router that provides NAT, DHCP, and wireless connectivity to the internal network.
*   **Centralized Device Control**: Demonstrates manual and automated control of IoT devices through a central Registration Server (Home Gateway) accessible via simulated Smartphones, Tablets, or PCs.
*   **Network Protocols**: Implements standard networking protocols such as DHCP for automatic IP assignment, ICMP for connectivity testing, and wireless security protocols (WPA2).

---

## 🛠️ Network Topology

The network topology is designed to reflect a realistic home setup:
1.  **ISP / Cloud**: Represents the external internet connection.
2.  **Home Gateway**: Acts as the central router, wireless access point, and IoT registration server.
3.  **End Devices**: PCs, Laptops, and Smartphones used by residents to access the network and control smart devices.
4.  **IoT Devices**: Various smart appliances connected wirelessly (or wired) to the Home Gateway.

## 🚀 Getting Started

### Prerequisites

To run this simulation and view the report, you will need:
*   **Cisco Packet Tracer**: Version 8.0 or newer is highly recommended to fully support all IoT features and devices used in this simulation.
*   **Microsoft Word** (or a compatible document viewer like Google Docs/LibreOffice) to open `CN report.docx`.

### Installation & Usage

1.  **Clone or Download**: Download this repository to your local machine.
2.  **Open the Simulation**:
    *   Launch Cisco Packet Tracer.
    *   Navigate to `File > Open` and select the downloaded `Smart_Home.pkt` file.
3.  **Interact with the Smart Home**:
    *   Wait a few moments for the network links to converge (turn green).
    *   Click on a simulated Smartphone or PC, go to the **Desktop** tab, and open the **Web Browser**.
    *   Navigate to the Home Gateway's IP address (usually configured as the default gateway) to access the IoT control panel and interact with the smart devices!
4.  **Read the Report**:
    *   Open `CN report.docx` for a deep dive into the design choices, IP subnetting, and network analysis.
