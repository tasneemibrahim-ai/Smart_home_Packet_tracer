# # Smart Home Packet Tracer Project

## Overview
This project is a Cisco Packet Tracer simulation of a Smart Home network. It demonstrates the integration of various smart devices within a home network environment, showcasing how IoT (Internet of Things) devices can be connected, configured, and managed.

## Contents
*   **`Smart_Home.pkt`**: The Cisco Packet Tracer project file containing the network topology and configurations for the smart home.
*   **`CN report.docx`**: The Computer Networks project report detailing the design, implementation, and analysis of the smart home network.

## Features
*   **IoT Integration**: Simulation of various smart home devices (e.g., smart doors, fans, lights, thermostats).
*   **Network Architecture**: A standard home network setup with a home gateway/router managing the internal network.
*   **Device Control**: Demonstration of how devices can be controlled automatically or manually through a central interface (like a smartphone or PC in the simulation).

## Requirements
*   **Cisco Packet Tracer**: You will need Cisco Packet Tracer installed on your machine to open and run the `.pkt` file. (Version 8.0 or higher is generally recommended for IoT features).
*   **Microsoft Word (or compatible)**: To view the project report (`CN report.docx`).

## Usage
1.  Clone or download this repository to your local machine.
2.  Open **Cisco Packet Tracer**.
3.  Go to `File > Open` and navigate to the downloaded repository.
4.  Select `Smart_Home.pkt` to load the simulation.
5.  Refer to the `CN report.docx` for detailed information on the network design and configurations.
